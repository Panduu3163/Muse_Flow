# MuseFlow 1.5.0

This release brings a more consistent look to MuseFlow and makes its visual choices easier to find and adjust.

## Appearance and navigation

- Choose Follow system, Light, Dark or AMOLED from four theme cards.
- Let the current album cover set the accent colour, or choose a hue and fine-tune it yourself.
- Preview fonts, display density and card sizes before choosing them.
- Search Settings for a control and jump to it. Reset Appearance, Player and Mini player choices independently.
- The navigation pill keeps the selected tab's icon and name visible while the other tabs show icons.

## Listening

- Choose Solid, Gradient, Blur, Live Mesh, Glow animated or Apple Music inspired Player backgrounds.
- Choose Default, Slim, Wavy or Squiggly progress controls, transport style, artwork crop, corners and rotation.
- Swipe the large cover to reveal the adjacent queued cover. The small Mini player cover shows playback progress around its edge.
- Apple-style lyrics stay readable over a translucent panel while the artwork backdrop remains visible.
- A liked heart stays pink with a soft glow. The current-track artwork indicator pauses with playback.

## Polish and reliability

- Search reads durations from more result formats and uses video metadata for pasted links when available.
- Shared spacing, shapes, touch targets, empty/error messages and reduced-motion behavior make the UI more consistent.
- Read changelog fetches this installed version's GitHub Release description once and saves it for offline reading.
- Appearance and Player quick presets are removed; their individual controls remain available.

This sideload release is signed with MuseFlow's existing app certificate so installations using that certificate can update in place. Android 7.0 and newer are supported.
