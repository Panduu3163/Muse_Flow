# MuseFlow 1.5.0 RC5 device checks

Install the beta over RC4 without clearing data (version code 27).

1. Select Apple Music inspired in Player > Background style. The Settings row must stay aligned, showing the selection beneath its title without duplicated text. Check System, Dot matrix and large Android font size.
2. Open full Player with bright, dark and multicolour covers. The top cover should dissolve into a blurred backdrop. Title, artists, progress times, queue and lyrics should remain readable. Watch the subtle backdrop motion while playing; it should stop with reduced motion.
3. In Player settings, the preview should stack its cover, title, progress and style label without overlapping or broken lines. Check every background style, Hide artwork, rotating artwork, narrow display width and large font size.
4. Progress bar style and Transport button style should each have an icon in the same rounded box as surrounding Settings rows. Their selected names should not crowd the title or arrow.
5. Select Wavy. Watch the broad smooth wave and thumb gap in both the picker and full Player. Pause, seek, resume, then enable reduced motion: the wave should flatten when not actively playing. Check tap, drag and TalkBack seek.
6. Select Squiggly. Check rounded curves with a gentle transition into the thumb, no dense jagged pattern, and the same shape in picker, preview and full Player. Repeat pause, seek, reduced-motion and accessibility checks.
7. Recheck Default and Slim progress styles, song skipping, Mini player Glow and the device navigation area for regressions.
