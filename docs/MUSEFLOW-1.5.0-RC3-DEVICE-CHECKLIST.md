# MuseFlow 1.5.0 RC3 device checks

Install this beta over RC2 without clearing data (version code 25).

1. In Appearance > Font style, choose each option, reopen the picker, and confirm all four card names and sample lines still show their own fonts. Check System, Serif, Monospace and Dot matrix in turn.
2. With Dot matrix selected, check screen headings, song titles, artist/secondary lines, button labels, settings rows and the Mini player. Titles should be larger, while supporting text uses regular dotted letters. Check a long title, large Android font size, and any non-Latin metadata in your library for clipping or fallback.
3. In Mini player settings, choose Glow animated. The preview and the actual Mini player should both show soft colours from their respective cover art moving inside the bar. Change tracks and verify the colours update; check a track without artwork uses a solid fallback.
4. Enable Android's reduced-motion/Remove animations setting. Glow should become still. Disable it and verify slow motion returns. Check Glow in both Light and AMOLED themes for readable controls and song text.
5. In Player settings, select Glow animated and compare the full Player. Check playback controls, lyrics and queue remain readable.
